Enhancing Types

Learn how to enhance your Sanity types with additional properties and validation rules.

Adding a Source for Slug Creation

defineField({
  name: 'slug',
  type: 'slug',
  options: {source: 'name'},
}),

Adding Preset Options to a string

defineField({
  name: 'armyType',
  type: 'string',
  options: {
    list: ['astra-militarum', 'adeptus-mechanicus'],
    layout: 'radio',
  },
}),

Adding an Initial Value

defineField({
  name: 'squadSize',
  type: 'number',
  initialValue: 5,
}),

Adding Context

defineField({
  name: 'squadSize',
  description: 'Number of models in the squad',
  type: 'number',
  initialValue: 5,
}),

Validation

Making a field Required

defineField({
  name: 'slug',
  type: 'slug',
  options: {source: 'name'},
  validation: (rule) => rule
    .required()
    .error(`Required to generate a page on the website`),
}),

The error message can be customized to provide more specific feedback to the user.

Custom Rules

defineField({
  name: 'imperialArmy',
  type: 'reference',
  to: [{type: 'army'}],
  validation: (rule) =>
    rule.custom((value, context) => {
      const isImperial = context?.document?.armyType === 'Imperial'

      // Triggers error if armyType is 'Imperial' but no reference is selected
      if (isImperial && !value) {
        return 'An Imperial army reference is required when armyType is "Imperial".'
      }

      return true
    }),
})

Conditional Fields

defineField({
  name: 'slug',
  type: 'slug',
  options: {source: 'name'},
}),

readOnly

defineField({
  name: 'imperialArmy',
  type: 'reference',
  to: [{type: 'army'}],
  // Disables editing ONLY IF a value has already been selected
  readOnly: ({value, document}) => Boolean(value) && document?.armyType === 'Imperial',
  validation: (rule) =>
    rule.custom((value, context) => {
      const isImperial = context?.document?.armyType === 'Imperial'

      if (isImperial && !value) {
        return 'An Imperial army reference is required when armyType is "Imperial".'
      }

      return true
    }),
})
